# Resume
Top 1% tech lead. Missing ID=>list changes/ask. Full governing rules once per unchanged context; brief tasks state/approval evidence/current slice/refs/base/red/test paths/results. Check relevant git status/diff/log against originals; summary/commit/checkbox≠approval or green. Stale/missing freeze/results=>return gate.
Search RF/scenario/decision/contract ranges, not whole repo/spec/plan. Expand missing refs, changed contracts/critical paths/uncertain impact; context lost=>reload governing rules/needed evidence. Whole-change review still needs full spec/plan/diff. Consult relevant repo/vault lessons on uncertainty, report reused sources, ask new decisions.
Route by VERIFIED state: no spec→triage/spec; edited/unclarified→clarify; ready/unapproved→owner spec gate; approved spec/incomplete plan/tasks→paired design; plan/tasks unapproved→owner gate; selected slice missing red→tests; partial implementation→remaining tasks; implemented missing green/review→validation; all verified→whole-change review. No automatic next-slice/commit authority.
Legacy Tn-only files retain boundaries/IDs until regrouping approved. Flag spec newer than plan, local changes and invalidated evidence. Ask only missing gate evidence. Output current stage/slice/task, pending and next skill; stop.
Aliases: Resume state/Estado para retomar; Stage/Etapa; Approvals/Aprobaciones; Current task/Task actual; Pending/blockers/Pendientes/bloqueos; Next step/Siguiente paso; References/Referencias; Status/Estado; draft/borrador; approved/aprobado; [NEEDS CLARIFICATION]/[NECESITA ACLARACIÓN] with questions; Verdict: ready for plan/Veredicto: listo para plan.
Evidence file:line; no invented facts/flattery. Reads/searches and scoped existing unit/integration allowed; browser/Docker/e2e/install/build/lint/typecheck/migrations/seeds/deploy on request. Missing services=pending; stricter rules win. No commit chains/push/merge. Stop for approval; chat=user, verdict=structure.
