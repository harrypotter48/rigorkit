# Optional vault
Personal Markdown vault optional; repo learnings shared; vault rules win.
## 1. Detect
Global/unversioned-local instructions: Vault: <path> · entry: <note> or Vault: none; entrada/no tengo aliases, clear paths valid; entry defaults Home. Unregistered: ask ONCE path/entry/new/none. None→propose, no copies; existing→Promote; new→From scratch then Promote. Approval before local registration; git check-ignore, else propose .git/info/exclude.
## 2. Tags
Only frontmatter tags, no keywords; vocabulary Tags.md (tag+synonyms/line), else repo tags. New tags require approval. Lowercase kebab-case, no type duplication (decision/learning; legacy aprendizaje).
## 3. Search
Map via Tags.md; matching tags: lines only in knowledge/decisions/repo learnings. Open matches only; none => filenames. Never whole vault.
## 4. Promote
Check EVERY learning incl teammates via path in source/fuente; never promotion status in repo. Missing: type/tipo decision→decisions/YYYY-MM-DD Title.md; else knowledge/<area>/Title.md, or vault structure. Generic: no code/internal names/business data/secrets; source `fuente: "repo:<repo>/specs/learnings/<file>"`. Parent link required. Approval per note; update duplicates. Learning aliases: type/tipo, status/estado, source/origen, updated/actualizado; knowledge/conocimiento, learning/aprendizaje, current/vigente; never override vault schema.
## 5. Connect
All notes reachable from entry/Home; mutual isolated links fail. Templates/instructions exempt. Propose reachable parent; after write add [[link]], trace incoming links to entry, report broken chain.
## 6. From scratch
Approved new vault at requested path: ONLY Home.md (Knowledge/Decisions, [[Tags]]), Tags.md (empty/repo tags), knowledge/, decisions/. Vault language/structure wins, Spanish too.
