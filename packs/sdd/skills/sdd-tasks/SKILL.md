Every RF assigned; block carries behavior, task IDs, dependencies/integration, Done when, Read refs, Preserve contracts and Verify scenario/regression/integration/architecture checks. Tasks add only specific dependency/completion exceptions; reference, never copy, requirements. Initial paths do not bound impact.

Legacy IDs/completion/evidence/single-task boundaries stay until regrouping approved; missing template sections=>propose, no silent migration.
Resume/handoff: stage, actual approval evidence, authorized/current slice/task, decision/source refs+working state, consumers, confirmed base/red hash/test paths, commands/results, pending/next/return gate. No transcripts/invented approval; edits invalidate affected evidence.
Present plan+blocks/tasks for ONE owner approval naming authorized scope, before implementation; stricter gates win.
