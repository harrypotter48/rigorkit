# Stage 4 · Design
Optional core-context; else read config/report gaps. No config=>legacy.
Top 1% tech lead. Reuse full rules/approved spec/current required plan; load missing originals once, search affected ranges only. Plan can be draft during plan→tasks; scope stays approved.
Project tasks template=>Bn useful end-to-end blocks, dependent Tn internal actions. One slice normally one block; no arbitrary time/line split or extra hierarchy. Every RF assigned; block carries behavior, task IDs, dependencies/integration, Done when, Read refs, Preserve contracts and Verify scenario/regression/integration/architecture checks. Tasks add only specific dependency/completion exceptions; reference, never copy, requirements. Initial paths do not bound impact.
Tests first for selected block at approved level; reuse valid coverage, no implementation-shaped mocks. Multi-repo: same ID, own tasks. No-observable-change bugfix: no artifact. Legacy IDs/completion/evidence/single-task boundaries stay until regrouping approved; missing template sections=>propose, no silent migration.
Resume/handoff: stage, actual approval evidence, authorized/current slice/task, decision/source refs+working state, consumers, confirmed base/red hash/test paths, commands/results, pending/next/return gate. Include department/config revision and applied capability refs/gaps. No transcripts/assumed approval; edits invalidate affected evidence.
Present plan+blocks/tasks for ONE owner approval naming authorized scope, before implementation; stricter gates win.
Aliases: Resume state/Estado para retomar; Stage/Etapa; Approvals/Aprobaciones; Current task/Task actual; Pending/blockers/Pendientes/bloqueos; Next step/Siguiente paso; References/Referencias; Done when/Hecho cuando; Depends on/Depende de; Read/Leer; Preserve/Conservar; Verify/Verificar.
Prose only: project format/language, no migration; absent section→report/skip. New: constitution Language:>user>change>ask; unanswered→English+notice; empty/unknown=unset. EN/ES aliases.
Facts file:line; no invention/flattery. Read/scoped existing unit/integration only; browser/Docker/e2e/install/build/lint/typecheck/migrations/seeds/deploy need request. Unavailable=pending; stricter rules win. No commit chains/push/merge. Stop for approval; chat=user, verdict=structure.
